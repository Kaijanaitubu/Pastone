### 共通仕様
全キャラ共通で以下の引数が使用できます。

- **b** : 眉差分
- **e** : 目の差分
- **m** : 口の差分

## 立ち絵の表示・表情切り替え
キャラを表示し、表情差分・腕差分などを操作するためのタグです。  
キャラが未表示の場合、使用と同時に自動で表示されます。
各キャラクターごとのタグの仕様は以下の通り

### 美寿花

#### [mizuka]

美寿花の通常衣装差分。

**引数**

| 変数名      | 説明                   |
| ---------- | ---------------------- |
| **b**      | 眉差分                  |
| **e**      | 目の差分                |
| **m**      | 口の差分                |
| **arm**    | 腕差分                  |
| **effect** | 顔効果（照れ、汗など）   |

[差分データフォルダ](../パストーン/data/fgimage/chara/mizuka/)

#### [mizuka_r]

美寿花の部屋着衣装差分。

**引数**

| 変数名      | 説明                   |
| ---------- | ---------------------- |
| **b**      | 眉差分                  |
| **e**      | 目の差分                |
| **m**      | 口の差分                |
| **arm**    | 腕差分                  |
| **effect** | 顔効果（照れ、汗など）   |

[差分データフォルダ](../パストーン/data/fgimage/chara/mizuka_r/)

### ロズ & ラズ

※内部的にはロズとラズは同一キャラとして扱われています。

#### [roz]

ロズを画面に登場・表情差分操作するときに使用。

**引数**

| 変数名      | 説明                   |
| ---------- | ---------------------- |
| **b**      | 眉差分                  |
| **e**      | 目の差分                |
| **m**      | 口の差分                |

[差分データフォルダ](../パストーン/data/fgimage/chara/RozLaz/roz/)

#### [laz]

ラズを画面に登場・表情差分操作するときに使用。

**引数**

| 変数名      | 説明                   |
| ---------- | ---------------------- |
| **b**      | 眉差分                  |
| **e**      | 目の差分                |
| **m**      | 口の差分                |

[差分データフォルダ](../パストーン/data/fgimage/chara/RozLaz/laz/)

#### [laz_bow]

ラズのお辞儀差分。

**引数**

* なし（固定差分）

#### [rozlaz]

ロズとラズが同時に映っている差分。

**引数**

* なし（固定差分）

#### [rozlaz_inai]

ロズとラズ両方が不在の差分。

**引数**

* なし（固定差分）

またすべてのタグは以下の引数が使用できる。

| 変数名        | 説明                                 | デフォルト値 |
| ---------- | -------------------------------------- | ----------- |
| **m_wait** | 口パーツ変更完了を待つかどうか            | false       |
| **m_time** | 口パーツの切り替えアニメーション時間（ms） | 600         |
| **top**    | 立ち絵の上方向オフセット                 | 20          |
| **z**      | 描画順（z-index）                       | なし        |
| **s_wait** | 立ち絵表示処理が終わるまで待つかどうか    | true        |
| **layer**  | 配置レイヤー番号                        | 0           |
| **s_time** | 立ち絵の表示アニメーション時間（ms）      | 1000        |
