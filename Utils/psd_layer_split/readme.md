# split.py

PSDファイル内のレイヤーを、**全レイヤーを包む最小の長方形サイズ**にトリミングした透過PNGとして出力します。
出力された各PNGは、PSD上の位置関係を正確に維持します。
(このReadmeはChatGPTにより出力されたものなどで本当に正しいかはチェックしてないです)
---

## 🧩 前提条件

1. **まとめたいレイヤーは、あらかじめラスタライズして結合しておく。**
   （スマートオブジェクト・調整レイヤー・テキストなどは自動的には反映されません）

2. **出力したいレイヤーはすべて「表示状態」にしておく。**
   非表示のレイヤーはデフォルトではスキップされます。

3. Python環境に以下のライブラリがインストールされていること：

   ```bash
   pip install psd-tools pillow
   ```

---

## 🚀 使い方

```bash
python split.py input.psd
```

### オプション

| オプション              | 内容                                      |
| ------------------ | --------------------------------------- |
| `-o <フォルダ名>`       | 出力フォルダを指定（省略時は `<PSD名>_layers_wrapped`） |
| `--include-hidden` | 非表示レイヤーも出力対象に含める                        |
| `-s <倍率>`          | 出力PNGの倍率を指定（例: 0.5で半分、2.0で2倍）既定=1.0    |

---

## 🎨 出力内容

* PSD内のすべての**表示レイヤー**を解析し、それらをまとめて包む**最小の長方形**を自動計算します。
* 各レイヤーは、その長方形サイズの透過PNGとして出力されます。
* レイヤー間の**相対位置関係は維持**され、透過背景が保持されます。
* グループ（フォルダ）構造はそのまま再現されます。

---

## 💡 例

### 入力PSD構成

```
人物
 ├─ 顔
 └─ 体
背景
 ├─ 空
 └─ 山
```

### 出力

```
input_layers_wrapped/
 ├─ 人物/
 │   ├─ 顔.png
 │   └─ 体.png
 └─ 背景/
     ├─ 空.png
     └─ 山.png
```

全レイヤーを重ねると、元のPSDと同じ構図になります。
ただし、出力画像は「必要最小限のキャンバスサイズ」に収まります。

---

## ⚠️ 注意事項

* スマートオブジェクトやフィルター効果は反映されません。必要なものは**事前にラスタライズ**してください。
* 透過PNGとして出力されるため、背景レイヤー（白や黒塗り）は不要です。
* PSD全体の座標を保持したい場合は、スクリプトにオフセット出力機能を追加してください。
